# 读懂你的项目：侧边对话助手

为有 C++ / Python 基础、信息学竞赛经验的数学系学生编写的本地交互教材。根据当前项目的真实实现，从数据、事件、状态和不变量切入，而不是先学整套前端框架。

## 打开

直接用 Chrome 打开本文件夹中的 **index.html**。双击即可，阅读与实验无需安装依赖、联网、API 密钥或运行扩展。请保留同目录的 CSS / JavaScript 文件。

如果希望通过本机网址阅读，在项目根目录执行：

```sh
python3 -m http.server 8765 --bind 127.0.0.1 --directory teach
```

浏览器打开 <http://127.0.0.1:8765/>。终端 `Ctrl+C` 停止服务；端口被占用时换一个端口。仅提供 teach 文件夹，不提供项目根目录。

直接 file 打开时，部分浏览器可能不允许持久保存进度；课程仍能阅读和实验。需要稳定保存时使用上面的本机网址。进度与诊断草稿只在当前浏览器、当前打开方式下保存；file 与 localhost 的记录不共享。

## 怎么学

共 10 课，建议每次 40–60 分钟，先预测，再看代码、操作实验、运行练习。

| 课 | 内容 | 关键能力 |
|---|---|---|
| 00 | 起点与路线 | 用输入、输出、状态描述自己的项目 |
| 01 | 运行与构建 | src → dist → 重新加载的闭环 |
| 02 | JS / TS 语法桥梁 | 用已有 C++ / Python 知识读真实表达式 |
| 03 | 架构地图 | 区分 content、background、options |
| 04 | 请求追踪 | 8 步跟踪引用、Port、SSE 与历史 |
| 05 | 异步与状态 | generation、竞态、队列、取消 |
| 06 | 数据与边界 | 请求构造、词元实验、存储与渲染 |
| 07 | 故障实验室 | 3 个人为故障，先失败再选择修复 |
| 08 | 维护实战 | 实际文件练习、测试、Git 范围控制 |
| 09 | 毕业挑战 | 自己写诊断报告，并查阅概念词典 |

每课都有明确过关标准。完成标记是自我记录，不是自动能力认证。源码按钮会在页内打开带行号的文件快照；查找框可查函数名并逐次跳转。顶部按钮可打印当前课或存成 PDF；交互页打印的是当前选中的实验状态，完整学习请用网页。

## 唯一故意失败的学习文件

`labs/delta-exercise.mjs` 故意含有一行覆盖错误，让你体验失败 → 最小修复 → 通过。

```sh
node teach/labs/delta-exercise.mjs
```

先看两段输入的断言失败，只修改 `joinDeltas`，不要删断言。这个文件不会访问扩展数据，也不是生产代码。网页里的实验也是缩小模型，不会修改真实仓库或向服务商发送请求。

## 教材文件

- `index.html`：静态页面结构。
- `styles.css`：桌面、窄屏和打印样式。
- `curriculum.js`：10 课内容、源码锚点、测验、链路与故障说明。
- `app.js`：章节导航、源码查看器、测验和实验。
- `source-data.js`：50 个源码、测试、配置和脚本文件的只读快照。
- `update-sources.mjs`：重新读取父目录的指定源码，只写本目录的快照文件。
- `check.mjs`：教材自动检查，复用项目已有 happy-dom / esbuild，不生成扩展构建产物。
- `labs/delta-exercise.mjs`：供学习者手动修复的独立练习。

## 更新与检查

正文基于 **2026-09-06** 的当前工作区，包含当时已有的未提交修改。不是只取最近一次 Git commit。采集时间与 SHA-256 显示在源码查看器中。

后续源码有变动，在项目根目录运行：

```sh
node teach/update-sources.mjs
node teach/check.mjs
```

第一条只更新源码快照，**不会自动更新课程的行为解释**。第二条检查锚点、章节导航、测验反馈、实验分支、进度、源码查看器，以及用真实源函数离线核对几个关键案例。语义改变后仍需人工更新对应课程。

检查依赖项目已有的 `happy-dom` 与 `esbuild`；若整个仓库没有 node_modules，先按根目录 package.json 与锁文件安装依赖。阅读教材不需要这些依赖。

```sh
node --check teach/app.js
node --check teach/curriculum.js
node teach/check.mjs
```

这些检查不会运行真实 Chrome E2E，也不是全项目验证。生产项目的命令、调试上下文和加载步骤见第 01、07 课。教学站新增文件全部位于 teach；原有源码与未提交改动保持不动。

## 内容依据

项目自身的当前源码与测试是主要依据；Chrome、TypeScript 和 MDN 的官方机制文档在相应章节直接链接。教材区分源码事实、类比、教学缩小模型和未来练习；没有把模拟实验的结果当成当前项目存在真实缺陷的证明。
